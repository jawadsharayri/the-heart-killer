THE HEART KILLER — CORONARY ARTERY DISEASE LEARNING SITE

Open index.html in a browser to view the website. Keep style.css, script.js, and the assets folder beside it; the page uses those local files.

The guide has five in-depth sections: causes, symptoms, effects, treatments, and prevention. The Anatomy Lab contains two clickable 2D SVG diagrams. Select labels to read each part's role, whether it is harmful, and additional context. Display choices are Light, Dark, High contrast, and Reading view.

The site is not published. See PUBLISHING.txt for GitHub Pages steps. This is educational material, not personal medical advice. It links to Mayo Clinic, CDC, Cleveland Clinic, and the American Heart Association.
